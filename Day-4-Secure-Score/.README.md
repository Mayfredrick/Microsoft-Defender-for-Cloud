## Understanding Secure Score

Secure Score helps provide an overall view of an organization's security posture.

It allows administrators to review the security state of their environment and identify areas where security improvements may be needed.

In this lab, I reviewed security controls related to areas such as unhealthy resources and attack paths.

## Secure Score and Security Baseline

Secure Score can help an administrator compare the security posture of an environment against recommended security practices.

This allows the administrator to identify areas that need improvement and use the available recommendations to strengthen the environment.

## Secure Score vs Security Recommendations

I learned that Secure Score and security recommendations have different purposes.

Secure Score:
Provides an overall measurement of the security posture of the environment.

Security Recommendation:
Provides specific guidance on actions that can be taken to address a security issue or improve the security posture.

A simple way I understand the difference is:

> Secure Score = How is the environment doing from a security posture perspective?
> Recommendation = What can be done to improve it?

## Reviewing Recommendations Before Making Changes

It is important to review a recommendation before applying it.

Reviewing the recommendation can provide more information about:

 The affected resources
 The security issue
 The recommended action
 Potential effects on other resources
 Possible effects on production
 Organizational security requirements and policies

An administrator should understand the possible impact before making a change.

## Identifying Affected Resources

Identifying affected resources is important because a recommendation may apply to specific resources or configurations.

Understanding the affected resources can help an administrator determine whether other connected resources could also be affected and whether additional investigation is necessary.

## Prioritizing Security Improvements

An administrator should not immediately apply every recommendation without reviewing it first.

Recommendations should be evaluated based on their potential security impact, affected resources, organizational policies, and possible effects on production.

Making changes too quickly could potentially disrupt production or negatively affect other resources.

## Using Secure Score to Improve Security

Secure Score can help an organization identify areas where its security posture can be improved.

By reviewing the score, security controls, and recommendations, administrators can identify areas that require attention and work toward improving the overall security posture of the environment.
