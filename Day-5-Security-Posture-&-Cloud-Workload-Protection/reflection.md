## Purpose of Microsoft Defender for Cloud

Microsoft Defender for Cloud helps organizations monitor and improve their cloud security posture.

It provides security recommendations that can help administrators identify security issues and determine what actions may be needed to improve the security of their resources.

It can also provide security alerts and other security information that can help administrators investigate potential threats.

## Security Posture Management vs Workload Protection

One concept I learned from this lab is that security posture management and workload protection have different purposes.

-Security posture management-- focuses on understanding the security condition of an environment, identifying weaknesses, and providing recommendations for improvement.

-Workload protection-- focuses on protecting specific cloud workloads and resources from security threats.

For example, an administrator can use security posture information to identify weaknesses while using workload protection capabilities to help protect resources from threats.

## Resources Protected by Defender for Cloud

Defender for Cloud can provide security capabilities for different types of cloud resources and workloads.

Examples include:

- Virtual machines
- Storage
- Databases
- Containers
- App services

The available protection depends on the Defender plans and services enabled in the environment.

## Understanding Defender Plans and Costs

It is important for an administrator to understand the available Defender plans before enabling them.

This helps the organization determine:
- Which resources need protection
- Which security capabilities are required
- What additional costs may apply
- Whether the protection is appropriate for the organization's needs

Understanding the plans can help prevent unnecessary costs.

## Secure Score and Security Recommendations

Secure Score helps provide an overall view of the security posture of an environment.

Security recommendations provide more specific guidance about what can be done to address security issues or improve the security posture.

I understand the relationship as:

-Secure Score = Shows the overall security posture.
-Security Recommendation = Provides guidance on what can be improved.

## Security Alerts vs Security Recommendations

Security alerts and security recommendations have different purposes.

-Security Alert:
Notifies an administrator about potentially suspicious or malicious activity that has happened or may be happening.

-Security Recommendation:
Provides guidance on how to address a security weakness or improve the security of affected resources.

This distinction helped me better understand the different use cases within Microsoft Defender for Cloud.

## Understanding Protected Resources

It is important to know which resources are being protected because administrators need to understand whether those resources meet security requirements and are appropriately protected.

This is especially important for resources that handle sensitive or important organizational data.

## Reviewing Security Settings Before Production

Security settings should be reviewed before applying them to production resources.

An administrator should understand the possible effects of a change before applying it. Incorrect settings could potentially cause service disruption, downtime, or other unexpected effects.

Testing and reviewing changes before production can help reduce these risks.
