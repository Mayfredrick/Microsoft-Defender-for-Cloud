## Secure Score

Secure Score evaluates the security posture of an environment based on security recommendations and provides a score that helps show how well the environment follows recommended security practices.

The score can help administrators identify areas where security can be improved.

## Security Recommendations

Security recommendations provide guidance on how to address security issues or improve the security of resources.

Information that can be found in a recommendation may include:

* Risk level
* Recommendation title
* Affected resources
* Risk factors
* Attack paths
* Recommendation owner
* Status

These recommendations can help administrators identify security risks and determine what actions may be needed.

## Security Alerts

Security alerts provide information about detected suspicious activity or potential security threats affecting resources.

Reviewing security alerts can help administrators understand potential threats and investigate security issues.

## Azure Monitor vs Defender for Cloud

One important concept I learned was the difference between Azure Monitor and Microsoft Defender for Cloud.

**Azure Monitor:**
Focuses on the performance and health of Azure resources.

**Microsoft Defender for Cloud:**
Focuses on security posture, security recommendations, and detected security threats.

Both tools can provide useful information, but they serve different purposes.

## Security Recommendations and Change Management

I learned that administrators should understand a security recommendation before making changes to a resource.

Not every change should be made immediately because a change could affect other resources or services. Reviewing the recommendation and considering the organization's security policies can help prevent unnecessary problems or service interruptions.
